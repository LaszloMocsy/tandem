## Description
Build the top of the page.

Hero:
- Headline "A task board you share with your coding agents."
- Subline "Tasks are Markdown files in your repo. Agents claim and finish them over MCP. You review."
- Slot for the download component (separate task) and a "View on GitHub" button.
- Small print: "Free and MIT licensed · macOS, Windows, Linux".
- Media slot built for the final video (`<video muted loop playsinline autoplay preload="none">` with poster), showing a static screenshot until the recording lands.

How it works, three steps, each with a real product mock built in HTML/CSS (not images):
1. Tasks are files: a task file snippet, highlighted with Astro's built-in Shiki; the "file is the card" visual, with the file beside its card and the `status:` line change shown as a one-line diff.
2. Agents use MCP: the `claude mcp add --transport http tandem …` command with a copy button, and a short `start_task` → `log_progress` → `finish_task` trace.
3. You review: a Review-column card with Mark reviewed and Reopen with feedback.

Coral marks human actions and blue-violet marks agent actions.
