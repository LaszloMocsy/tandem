## Description
Add a `site` job to `.github/workflows/ci.yml` that runs only when `site/**` (or the workflow itself) changes: set up bun, `bun install --frozen-lockfile`, `bun run check`, `bun run test`, `bun run build`. Optionally add Lighthouse CI against the built site with 95+ budgets for performance and accessibility.

## Acceptance criteria
- [x] The job runs on PRs and pushes to `main` that touch `site/`, and is skipped otherwise
- [x] It runs check, tests and build
- [x] Existing Rust and `ui/` jobs are unchanged
